# Analog

Analog (AnalogJS) is the fullstack meta-framework for building applications
and websites with Angular, powered by Vite and Nitro.

Features:

- Supports Vite/Vitest/Playwright
- Server and deployment integrations powered by Nitro
- File-based routing
- Server-side data fetching
- Support for using Markdown as content routes
- Server routes (API routes)
- Fully-static (SSG) or hybrid SSR/SSG rendering

Get started: `npm create analog@latest` (package `create-analog` on npm).

(e.g. https://analogjs.org/docs/introduction.md), or by sending
`Accept: text/markdown` to the page URL.
