# Privacy

analogjs.org is the documentation site for the open-source Analog framework.
It has no user accounts, no sign-ups, and collects no personal information
directly.

- **Analytics** — the site uses Google Analytics with IP anonymization
  enabled to understand aggregate traffic. See Google's privacy policy
  (https://policies.google.com/privacy). Blocking the googletagmanager.com
  script disables analytics entirely without affecting the site.
- **Search** — documentation search is provided by Algolia DocSearch; search
  queries are sent to Algolia to return results
  (https://www.algolia.com/policies/privacy/).
- **Local storage** — your theme choice (light or dark) is stored in your
  browser's localStorage and never leaves your device.

Questions about this page or the project's data practices can go to
brandon@analogjs.org or an issue on https://github.com/analogjs/analog.
