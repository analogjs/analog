# Contact

Analog is an open-source project — most conversations happen in public.

- GitHub issues: https://github.com/analogjs/analog/issues — bug reports and
  feature requests.
- GitHub discussions: https://github.com/analogjs/analog/discussions —
  questions, ideas, and show-and-tell.
- Discord: https://chat.analogjs.org — community support, Q&A, general chat.
- Stack Overflow: https://stackoverflow.com/questions/tagged/analogjs
- X (Twitter): https://twitter.com/analogjs — announcements and news.

Email:

- Support and general inquiries: brandon@analogjs.org
- Sponsorships: sponsor@analogjs.org
- Partnerships: partnerships@analogjs.org

Security reports: use GitHub private vulnerability reporting
(https://github.com/analogjs/analog/security/advisories/new) rather than a
public issue.
